# Product Plan

## Problem

AIは何でもできるため、AIを使ったことがない編集者には「何を頼めばいいのか」が分かりにくい。

## Hypothesis

AIそのものを増やすのではなく、用途を「壁打ち」に絞り、音声中心のUIにすることで既存AIを使っていなかった人でも利用しやすくなる。

## MVP

出版企画グリル。

- 音声会話
- 7問の企画フレーム
- 回答に応じた深掘り
- 必要に応じたリサーチ
- 企画書への構造化
- 保存

## Backend direction

第一候補:
- GCP
- Gemini API
- Google Workspace / Drive

接続候補:
- GitHub

## Non-goals

- 汎用AIチャットを作らない
- 高機能な文書エディタを最初から作らない
- AIモデル自体を開発しない
- 保存先をユーザーに選ばせすぎない

## Future

出版企画以外にも、動画企画、Podcast企画、研究テーマ、プロジェクト相談などへシナリオを追加できる。
