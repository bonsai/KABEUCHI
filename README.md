# KABEUCHI

AIとの会話を「壁打ち」に変えるための実験。

## Core idea

AIに答えを出させるのではなく、人間の考えを質問・反論・整理によって掘り出す。

入口は音声を基本とし、ユーザーには複雑なAIや保存先を意識させない。

## First use case: 出版企画グリル

新しい本の企画を、7つの質問から始める。

1. 何についての本なのか
2. なぜ今その本を書くのか
3. 誰に届けたいのか
4. 読者が得るものは何か
5. 著者ならではの経験・視点は何か
6. 既存の本と何が違うのか
7. どんな本として完成させたいのか

7問は固定フォームではない。回答から次の質問を変え、必要なら深掘りする。

## Conversation loop

発話 → Intent → Prompt → 質問 → 回答 → 状態更新 → 次のIntent/Prompt → 深掘り → 構造化 → 成果物

## Product principle

- 機能を増やさない
- 音声を主役にする
- AIの存在を意識させない
- GitHub / Google Driveなど保存先を隠蔽する
- まず既存AIで成立するか検証する
- 独自開発は「既存AIが使いにくい部分」に限定する

## MVP

最初は「出版企画を7問でグリルする」だけ。

成果物は、企画概要・想定読者・著者の強み・差別化・仮タイトル・章立て案など。

保存先はGoogle Driveを第一候補とし、GitHubも接続可能な構造にする。

## Architecture direction

GCP + Google Workspaceを中心に、Gemini APIを会話・構造化エンジンとして利用する。

Web UI → 音声入力 → KABEUCHI conversation engine → Gemini → Google Drive / GitHub

ただし、無料範囲で成立する最小構成を優先する。

## What is 壁打ち?

自分の考えを相手に投げ、質問やツッコミを受けながら考えを整理・深化する対話。

答えを受け取ることではなく、考えを磨くことが目的。
